Kernel tests

vLLM's own regression tests for the GLM-5.3-Flash kpool kernels (tests/kernels/test_kpool_decode_update_batched.py, pinned by hash), plus a rejected-draft reproduction, run inside each engine image. The four upstream failures are exactly the tests written for vllm#57477 and vllm#58454; the patches (tpurtell PR #5, shipped in 0.9.0) fix all of them.

Engine labels. 0.9.0 is 0.8.0 plus the kpool patches (tpurtell PR #5; the patched kernel files are byte-for-byte identical to the 0.9.0 release), plus two changes that do not affect these measurements at defaults: an opt-in prefix-cache lookup (off by default) and usage reporting. Rows labelled 0.8.0 + patches ≈ 0.9.0 are therefore the same serving engine as rows labelled 0.9.0; the patched 0.8.0 rows were measured before 0.9.0 was released. Plain 0.8.0 is the unpatched release. 0.7.0 + patches is a separate backport, not 0.9.0.
