Hard-question screen

The five GPQA questions that most often came back empty, each run 8 times (40 runs per configuration), to compare how often configurations fail to finish long reasoning. A loop is repetitive reasoning to the cap; an exhaustion is varied reasoning that runs out of budget.

Read with care. The questions were chosen from engine 0.8.0's failures: comparisons within one engine are fair, but the cross-engine gap here is an upper-end estimate (the full GPQA runs carry that finding). Repeats use one fixed seed and still differ because concurrent batching changes the arithmetic. Outcomes cluster by question, so the Wilson intervals are too narrow.
