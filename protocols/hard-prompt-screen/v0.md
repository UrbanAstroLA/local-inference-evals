# hard-prompt-screen / v0

Identical to `v1` (same items, sampling, seed, schedule, classes) except that there is **no early stop**: every
request runs until it stops or reaches 327,680 tokens. Used for the 2026-09-30 runs.

The v1 early-stop rule was validated on the 80 v0 traces (stopped 27/28 loops, 0/44 completions, 0/8 exhaustions),
so the two versions classify the same way on that set. They are still kept as separate protocol versions and are not
mixed in comparisons.
