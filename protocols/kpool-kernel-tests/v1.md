# kpool-kernel-tests / v1

Regression tests for the GLM-5.3-Flash kpool indexer tail kernels.

1. **Upstream suite:** `tests/kernels/test_kpool_decode_update_batched.py` from vllm-project/vllm at commit
   `69d5c81fcd` (sha256 prefix `698d688693f37ba8`), run with pytest inside the image under test on one GPU:
   `docker run --rm --gpus device=0 -v $PWD/t.py:/t/t.py:ro -w /t --entrypoint python3 <image> -m pytest -q /t/t.py`.
   The tests written for vllm#57477 and vllm#58454 are `test_prefill_seed_honors_padded_tail_block_stride`,
   `test_rejected_draft_redo_needs_ring_slots[2]`, `test_decode_writer_matches_prefill_writer[2-4]` and `[2-16]`.
2. **Rejected-draft reproduction** (`tools/kernel/kpool_rejected_draft_test.py`): builds a pool, verifies with a
   rejected pool-completing draft at 1, 2, 3, 5 and 7 draft tokens, and compares the pool with a no-speculation
   reference. Auto-detects a patched kernel and sizes the ring as upstream does.
