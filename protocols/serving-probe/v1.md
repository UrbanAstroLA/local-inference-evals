# serving-probe / v1

Short, controlled measurements of a running server, using the first 16 GPQA Diamond doc ids (0-15) under
`gpqa-diamond/v1` prompt rendering.

- **Sampled:** temperature 1.0, top_p 0.95, seed 1234, max_tokens 4,096, thinking on, at concurrency 1 and 8.
  Reported: aggregate tok/s, median per-request decode tok/s, median time to first token, and from the server's
  `vllm:spec_decode_*` counters (delta over the batch): acceptance rate (accepted / drafted), mean acceptance length
  (1 + accepted / drafts), per-position acceptance.
- **Greedy:** temperature 0, max_tokens 2,048, one request at a time. Outputs are compared pairwise by the number of
  identical leading characters. A configuration run twice gives the noise floor. Only lengths and hashes are
  published, never output text.
