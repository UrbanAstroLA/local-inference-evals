# tool-eval-bench / v1

Tool-calling regression check with tool-eval-bench 2.6.1.dev45 (commit `cf54b4b`): all 88 scenarios (TC-01 to TC-88),
temperature 0, thinking on, 8 scenarios in parallel, at most 8 turns, 900 s timeout, reference date 2026-09-04, served
through the engine's OpenAI-compatible API with its tool-call parser. Two repeats per configuration on one server.

**Per row:** `rep`, `scenario_id`, `status` (pass / partial / fail) and `points` (2 / 1 / 0) as the benchmark scores
them. Transcripts, tool arguments and model output are not published.
**Summary:** per repeat: points of 176, and pass / partial / fail counts.

Temperature 0 does not make a batched engine deterministic (see `FINDINGS.md`); repeats can differ, so scenarios are
compared across repeats, not single runs.
